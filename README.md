# ENGENHARIA-DE-SOFTWARE-
Fabrício tarefa
As características mais importantes são:

Capacidade de realizar as funções propostas (funcionalidade)

Facilidade de uso para o usuário (usabilidade)

Confiabilidade no funcionamento sem falhas (confiabilidade)

Desempenho rápido e otimizado (eficiência)

Facilidade para realizar ajustes e melhorias (manutenibilidade)

Proteção contra acessos não autorizados e falhas (segurança)

Facilidade para ser testado e validado (testabilidade)

Capacidade de funcionar bem em diferentes ambientes e sistemas (compatibilidade)
